# 📈 Sales Prediction

## 🚀 Overview
A regression-based project to predict product sales based on advertising expenditure.

## 🎯 Objective
To analyze the relationship between advertising channels and sales performance.

## ⚙️ Methodology
- Cleaned and explored dataset
- Performed correlation analysis
- Trained a Linear Regression model
- Evaluated using R² and error metrics

## 🛠️ Tech Stack
Python | Pandas | NumPy | Matplotlib | Seaborn | Scikit-learn

## 📊 Outcome
A strong relationship between advertising spend and sales was observed, enabling accurate sales predictions.
