# 📉 Unemployment Analysis

## 🚀 Overview
A data analysis project focused on understanding unemployment trends using real-world datasets.

## 🎯 Objective
To analyze unemployment rates across regions and study the impact of COVID-19 on employment patterns.

## ⚙️ Methodology
- Cleaned and merged multiple datasets
- Standardized date and region formats
- Performed Exploratory Data Analysis (EDA)
- Visualized trends using graphs and charts
- Analyzed regional and temporal variations

## 🛠️ Tech Stack
Python | Pandas | NumPy | Matplotlib | Seaborn

## 📊 Key Insights
Significant spikes in unemployment were observed during the COVID-19 period, with clear regional variations across India.
