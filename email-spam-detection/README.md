# 📧 Email Spam Detection (NLP)

## 🚀 Overview
A Natural Language Processing project that classifies messages as spam or non-spam.

## 🎯 Objective
To build a reliable spam detection system using text data and machine learning.

## ⚙️ Methodology
- Cleaned and preprocessed text data
- Applied TF-IDF vectorization for feature extraction
- Trained a Multinomial Naive Bayes model
- Evaluated performance using classification metrics

## 🛠️ Tech Stack
Python | Pandas | NumPy | Scikit-learn | NLP (TF-IDF)

## 📊 Outcome
The model achieved ~98% accuracy and effectively classified spam and non-spam messages.
