# 🚗 Car Price Prediction

## 🚀 Overview
A machine learning regression project to predict the resale value of used cars.

## 🎯 Objective
To estimate car prices based on key features such as fuel type, mileage, and vehicle age.

## ⚙️ Methodology
- Performed data preprocessing and feature engineering
- Converted categorical variables into numerical format
- Trained a Random Forest Regressor
- Evaluated model performance using R² score and error metrics

## 🛠️ Tech Stack
Python | Pandas | NumPy | Matplotlib | Seaborn | Scikit-learn

## 📊 Outcome
The model achieved strong prediction accuracy (R² ~0.88) and identified key factors influencing car prices.
